# S0上板验证

状态：待用户确认。2026-10-05。本地标签 `v0.4.0-stability-s0-local.1`，未上传GitHub。

下载本目录[demo.bit](demo.bit)，不要使用运行目录/best_result。恢复用[v0.3.0固定bit](../v0.3.0/demo.bit)。新候选不继承旧bit上板结论。

1. 使用原有正常TF卡/HDMI音频设备，记录设备信息；四张640x480、24位未压缩BMP。
2. 冷启动5次，确认扫描、首图、编号正常；首图前静音，实际提交后一次提示与对应琶音。
3. KEY1/KEY2各连续操作至少10次，包括首尾循环和加载中按键，确认挂起行为、完整画面和音频联动。
4. KEY4切换MAN/AUTO，四个SW模式和返回图片模式保持既有行为；AUTO至少10分钟。
5. 空闲KEY3复位5次；若触发已知卡0，记录频率和恢复方式。S0未修SD缺陷，扫描拔卡/密集翻图复位留作S4对照。
