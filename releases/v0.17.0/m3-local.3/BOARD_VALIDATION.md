# v0.17.0 M3 板测步骤（m3-local.3）

只下载 releases/v0.17.0/m3-local.3/demo.bit。回退：releases/v0.17.0/m3-local.2/demo.bit（已板测通过），或 releases/v0.16.0/demo.bit。

推演时间 t 仍由**临时测试源**驱动：每次切图（含转场后重新显示同一张图）t 从 0 开始，每 2 帧加 1，到 239 后回到 0，一圈约 8 秒。没有按键控制，不需要切换拨码。

## 准备卡

- **卡 A（原素材）**：v0.16.0 板测用的 24 位 PIC1–4.BMP 和 BGM.PCM。
- **卡 B–E（v3 四张灾害卡）**：每张卡放一组 PIC1–4.BMP（每张 1228854 字节），再放卡 A 的 BGM.PCM。本次仿真重新生成的 16 张图与下面目录里的文件逐字节一致。

| 卡 | 灾害 | 文件目录 |
|---|---|---|
| B | 滑坡 | `tools/scenes/landslide_village/out/sd/` |
| C | 泥石流 | `tools/scenes/debris_village/out/sd/` |
| D | 山洪 | `tools/scenes/flood_village/out/sd/` |
| E | 地震 | `tools/scenes/quake_village/out/sd/` |

每张卡的四张图依次是：PIC1 致因、PIC2 发生（近景）、PIC3 后果（全景）、PIC4 撤离。

## A. 灾害图层（卡 B–E）

预期效果与之前确认过的 Python 原型 GIF 一致，以 GIF 为准：

| 卡 | PIC1 致因 | PIC2 发生 | PIC3 后果 |
|---|---|---|---|
| 滑坡 | 强降雨；隐患坡体黄色虚线框慢闪 | 坡顶弧形裂缝张开，坡体变暗下沉，有下移纹理；落石沿路线滚落；后期坡脚扬尘 | 坡脚堆积扩大，掩埋道路房屋 |

| 山洪 | 上游强降雨，河水上涨 | 浑水涨满河道并漫上岸 | 淹没范围按时长加深 |
| 地震 | 断层发红，地震波从震中扩散；**没有雨** | 画面左右晃动并衰减，房屋裂纹和扬尘，地裂缝 | 次生崩塌、落石 |

PIC4 撤离（四张卡统一）：危险区红色斜线，绿色路线朝避险点流动，避险点闪烁；路线和避险点不进入红色危险区。

1. 每张卡逐张看 PIC1–4，效果与上表和原型 GIF 一致；每次切图都从头开始，不带上一张的进度。
2. 雨：PIC1–3 整屏都在下（PIC1 较密），远近两层，没有闪电；PIC4 和地震卡没有雨。
3. 地震 PIC2：只左右晃，不上下晃；晃动时画面边缘没有花屏或错行，晃动停下后画面回到原位。
4. 图层与底图对齐：裂缝、泥流、洪水、路线、避险点都落在底图的对应地物上；没有整体偏移；画面四边和行消隐处没有异色像素。
5. 亮度/对比度调节作用在合成后的画面上；转场时图层随画面一起淡入淡出或擦除。
6. 缩略图四宫格：四张都是底图原色，没有灾害色、雨和晃动；回到全屏后图层从头开始。
7. （可选）混合卡：24 位图与灾害图交替轮播，24 位图始终不着色。
