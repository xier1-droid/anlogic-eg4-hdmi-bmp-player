# 场景标注工具使用说明

`annotate_scene.exe`（源码 `tools/annotate_scene.py`）用来人工制作一张"山区避险课堂"场景卡。在 4 张阶段图上用鼠标点出裂缝、洪水范围、危险区、撤离路线和避险点，工具会生成可以直接拷到 SD 卡的 `PIC1.BMP`–`PIC4.BMP`。

整个过程不需要写代码，也不需要手写坐标。

> **第一次用？** 先跟着 [滑坡卡制作教程.md](滑坡卡制作教程.md) 一步一步做一张卡，再回来查这份说明。

---

## 1. 先了解：一张场景卡是什么

一张卡是 4 张图，按顺序在板上播放，每张图都有自己的动画：

| 阶段 | 文件 | 角色 | 画面内容 | 板上动画 |
|---|---|---|---|---|
| 1 | PIC1 | 致因 | 灾害发生前：暴雨、易发地段 | 雨丝，隐患区黄色虚线框慢闪 |
| 2 | PIC2 | 发生 | 灾害正在发生（常用近景） | 裂缝延伸、洪水推进、泥石流涌下等 |
| 3 | PIC3 | 后果 | 灾害过后：淹没、堆积、掩埋 | 堆积体或淹没范围扩展 |
| 4 | PIC4 | 撤离 | 往哪里跑 | 危险区红色斜纹，绿色路线流动，避险点闪烁 |

板上每张图播放约 8 秒。工具和板子都用一个 **0–239 的"时刻"** 描述动画：0 是开始，239 是结束，大约 30 个时刻是 1 秒。

标注的本质就是告诉板子两件事：

- **哪些像素属于哪种东西（区域）**，比如"这是撤离路线""这是危险区"；
- **它们什么时候出现（时刻）**，比如"路线从村子开始，第 200 时刻画到避险点"。

FPGA 只按这两项信息实时渲染，不认识具体是哪张图。所以换一套图、重新标注，就是一张新卡，板上的程序不用改。

## 2. 准备工作

### 2.1 运行工具

- **推荐**：双击 `tools/annotate_scene.exe`。不需要安装 Python，拷到其他电脑上也能用。
  - 第一次启动要等几秒，exe 需要先自解压。
  - 如果杀毒软件拦截，选择"允许"即可。
- 把某个 `scene.yaml` 拖到 exe 图标上，会直接打开这个场景。
- 用源码运行：`python -I tools/annotate_scene.py [scene.yaml]`。需要 Python 3，并装好 pillow、numpy、pyyaml。

### 2.2 准备 4 张图

- 4 个阶段可以各用一张图。同一地点的 1、3、4 阶段最好构图一致（同一视角），否则观众看不出前后关系。
- 只有 1 张图也可以，4 个阶段会共用它。
- 任意尺寸都行。工具会居中裁成 4:3，再缩放到 640×480。所以重要内容不要放在图片的左右边缘或上下边缘。
- **文件名排序决定阶段顺序**。建议命名为 `1_致因.png`、`2_发生.png`、`3_后果.png`、`4_撤离.png`。

## 3. 界面

```
┌──────────────────────────────┬─────────────┬────────────────────────┐
│                              │ 场景        │ 本阶段的标注（列表）     │
│                              │  灾害 缩放   │  1. 掩膜 · 1 危险区      │
│         画  布                │ 阶段        │  2. 折线 · 0 撤离路线     │
│   （在这里点选，滚轮无作用）    │  PIC1–PIC4  │  [上移][下移][删除]       │
│                              │  名称 角色   │  [添加掩膜…][设种子掩膜…] │
│                              │  底图        ├────────────────────────┤
│                              │ 工具        │ 说明 / 取舍理由           │
│                              │  ○选择 ○折线 ├────────────────────────┤
│                              │  ○多边形 …   │ 预览与生成               │
│                              │ 参数        │  ○标注 ○T 图 ○动画 [播放] │
│                              │  区域 线宽   │  ──────●───── 时刻滑条    │
│                              │  t0 t1 …    │  [检查本阶段][保存并生成] │
├──────────────────────────────┤             ├────────────────────────┤
│ 状态栏：x 312 y 205  区域…    │             │ 日志                    │
│ 提示栏：当前工具怎么用         │             │                        │
└──────────────────────────────┴─────────────┴────────────────────────┘
```

- **状态栏**：显示鼠标所在像素的坐标。已经算出 T 图时，还会显示这个像素属于哪个区域、在哪个时刻出现。
- **提示栏**：显示当前工具的操作方法。
- **日志**：显示检查结果、生成结果和所有报错，有问题先看这里。
- **缩放**：画布可以按 1、1.25、1.5、2 倍显示。启动时会自动选能放进屏幕的最大倍数。缩放只影响显示，坐标始终按 640×480 记录。

## 4. 快速上手：10 分钟做一张卡

1. **文件 → 新建场景…**
   1. 选一个**空目录**，例如先在 `tools/scenes/` 下新建 `my_village`，再选中它。
   2. 选灾害类型：山洪、滑坡、泥石流或地震。
   3. 选 4 张阶段图，可以按住 Ctrl 多选。
   4. 工具会把图片存成 `pic1.png`–`pic4.png`，并生成 `scene.yaml`。
2. **逐个阶段标注**：点 `PIC1`–`PIC4` 切换阶段，每个阶段先在"名称"里写一句话，例如"撤离：向两侧高处转移"。
   - PIC1 致因：用**轮廓线**圈出隐患区。
   - PIC2 发生：用多边形、折线或种子点画出灾害的发展，并设好 t0、t1，让它按时间推进。
   - PIC3 后果：画出堆积或淹没范围。
   - PIC4 撤离：
     1. 用**画笔**涂出危险区（边界规整时也可以用多边形）；
     2. 用**折线**从村子画到安全高地；
     3. 用**避险点**在终点放一个点。
3. **每个阶段画完后**：
   1. 切到"动画"预览，点"播放"，看效果；
   2. 点"检查本阶段"，看日志里有没有 ✗ 或 ⚠。
4. **保存并生成场景包**：等日志出现"✓ 完成"，打开输出目录。
5. 把 `out/sd/` 里的 `PIC1.BMP`–`PIC4.BMP` 拷到 **SD 卡根目录**，插卡上板。SD 卡上原来的同名文件会被覆盖，请先备份。

## 5. 画图操作

### 5.1 通用操作

| 操作 | 作用 |
|---|---|
| 左键单击 | 放下一个点 |
| 右键 / 双击 / 回车 | 结束当前形状 |
| Backspace | 删掉刚放的最后一个点（画到一半时） |
| Esc | 放弃正在画的形状；没有在画时，取消选中 |
| `[` / `]` | 笔刷缩小 / 放大 |
| Delete | 删除选中的形状 |
| Ctrl+Z | 撤销（最多 50 步） |
| Ctrl+S | 保存 |

画到一半时，白色虚线会跟着鼠标走，方便看下一段的方向。

> ⚠ **选中的形状会"吸住"鼠标**：用折线、多边形等工具时，如果列表里**选中了某个形状**，在它的顶点附近（约 10 像素内）点下去，工具会认为你想拖动那个顶点，而不是放新点。画完一个形状后工具会自动取消选中，所以接着画下一个（哪怕从同一点出发）不受影响；如果是在列表里点选过某项，先按 **Esc** 取消选中再画。

### 5.2 八种工具

| 工具 | 用法 | 适合画 | 至少几个点 |
|---|---|---|---|
| **选择 / 拖点** | 点击某个形状的顶点选中它，按住拖动移动顶点；点空白处取消选择 | 修改已有标注 | — |
| **折线** | 沿路径逐点点击。**起点最早出现，终点最晚出现** | 撤离路线、裂缝、断层、落石路径 | 2 |
| **多边形** | 沿区域边界逐点点击，结束时自动闭合并填满 | 边界比较规整的区域：倒塌房屋、滑坡体 | 3 |
| **画笔** | 按住左键涂抹，见 5.3 | 边界弯曲的区域：河道、淹没低地、堆积扇、危险区 | — |
| **橡皮擦** | 按住左键擦除选中区域的一部分，见 5.3 | 修改画笔区域、掩膜、种子掩膜 | — |
| **轮廓线** | 和多边形一样，但只画边框不填充 | 致因图里的隐患区虚线框 | 3 |
| **种子点** | 在扩散起点点一个或几个点，从这里向外按距离扩散 | 洪水漫延、堆积扇展开 | 1 |
| **避险点** | 点击避险棚或安全空地的中心，一次放一个 | 撤离图的避险点 | 1 |

**画折线的技巧**：
- 沿着图里真实的小路、田埂点，拐弯处多点几个点，路线才贴合道路。
- 撤离路线一定要**从危险的地方画向安全的地方**。方向画反了，动画就会从避险点往村子里流。

**种子点必须限定范围**，否则会扩散到整张图。三种做法：
- **最方便**：在列表里选中种子点，切到**画笔**，把它能流过的地方涂出来。比如洪水只能在河谷低地流，就把河谷涂满。见 5.3。
- 在外部画一张"可通过范围"的黑白图（白色可以流过，黑色挡住），选中种子点后点"**设种子掩膜…**"导入。
- 在参数里设"**最远距离**"（像素）。

### 5.3 画笔和橡皮擦：涂不规则区域

河道、淹没低地、堆积扇这类边界弯弯曲曲的区域，用画笔直接涂比用多边形点快得多。

**画一块新区域**：
1. 确认列表里**没有选中任何形状**。选中了就先按 Esc。
2. 在"参数"里选好**区域**、t0，需要时再选渐进方向和边缘起伏。撤离阶段的画笔默认区域就是"危险区"。
3. 选"画笔"工具，在画布上按住左键涂。画布上的白色圆圈表示笔刷大小，用 `[` `]` 或参数里的"笔刷半径"调整。
4. 松开鼠标后，列表里会多出一项"画笔 · 区域…"，并保持选中。**接着涂会继续加在这一块上**，可以分很多笔涂完。
5. 要另画一块不同区域，先按 Esc 取消选中，再改区域、开始涂。

**修改已有区域**：
- 在列表里选中一项画笔区域、导入的掩膜，或者带种子掩膜的种子点。
- 选"画笔"往上加，选"橡皮擦"擦掉一部分（橡皮擦圆圈显示为红色）。
- 切换到画笔或橡皮擦时，选中状态会保留。

**画笔不会改动你的原文件**：
- 画笔涂的内容存成场景目录里的黑白 png，文件名为 `brush_p阶段_序号.png`，在**保存时**才写入。没保存就关闭，涂抹不会留下。
- 对**导入的掩膜**（比如 `fan_mask.png`）涂改时，工具会先复制成新的 `brush_….png` 再改，日志里会提示。原文件保持不变，其他阶段引用它的地方也不受影响。

**撤销**：Ctrl+Z 每次撤销一笔（从按下到松开鼠标算一笔）。

> 涂完切到"T 图"或"动画"看一下效果；需要的话，用"边缘起伏"让边缘更自然。

### 5.4 外部掩膜

习惯用 PS 的话，也可以在外部画好掩膜再导入：

1. 在 PS、GIMP 或 Windows 画图里打开这个阶段的 `picN.png`（场景目录里有），保证尺寸与底图相同（640×480）。
2. 新建一层，用白色涂出区域，其余全部涂黑，导出成 png。最简单的做法是把这层单独存成黑底白图。
3. 在工具里先在"参数"中选好**区域**，再点"**添加掩膜…**"选择这张图。
   - 掩膜不在场景目录时，工具会自动拷进去。
   - 灰度值 ≥128 算作区域，其余不算。

### 5.5 参数

"参数"框有两种用途：

- **没有选中形状时**：设置**下一个要画的形状**。
- **选中了形状时**：直接修改**这个形状**，按回车或离开输入框后生效。

| 参数 | 含义 | 对哪些形状有效 |
|---|---|---|
| 区域 | 这个形状属于哪种东西，下拉选项随灾害和角色变化，见第 6 节 | 全部（避险点除外） |
| 线宽 | 线条宽度（像素）。路线建议 4，裂缝 2–3 | 折线、轮廓线 |
| 开始时刻 t0 | 形状开始出现的时刻（0–239） | 全部 |
| 结束时刻 t1 | 形状完全出现的时刻。折线从起点画到终点用的时间就是 t0→t1 | 折线、种子点、带渐进方向的多边形、画笔区域或掩膜 |
| 边缘起伏 | 让多边形、画笔区域或掩膜的边缘随机起伏几个像素，看起来更自然。0 表示不起伏 | 多边形、画笔区域、掩膜 |
| 最远距离 | 种子点最远扩散多远（像素）。0 表示不限，此时要配合种子掩膜 | 种子点 |
| 避险点半径 | 避险点圆的半径（像素），默认 9 | 避险点 |
| 笔刷半径 | 画笔和橡皮擦的半径（像素），默认 12，也可以用 `[` `]` 调 | 画笔、橡皮擦 |
| 渐进方向 | 区域按"自上而下"或"自左向右"在 t0→t1 之间逐渐出现。"无"表示 t0 时整块同时出现 | 多边形、掩膜 |

**时刻怎么选**：板上约 8 秒播完 0–239。经验值：
- 撤离路线用 0→200，最后约 1 秒让观众看清完整路线；
- 洪水用 0→239；
- 后发生的东西（如沟壁溅泥）t0 设 30 以上，让它在主体之后出现。

时刻在板上按 4 一档取整，相差 1–3 看不出区别。

### 5.6 列表：管理本阶段的形状

右上角的列表显示本阶段的所有标注，格式为"序号. 类型 · 区域 · 时刻 · 文件"。避险点排在最后。

- 点列表里的一项可以选中它，画布上会出现白色小方块标出顶点，参数框同时显示它的参数。
- **上移 / 下移**：形状重叠时，**列表里靠下的形状盖住靠上的**。比如撤离路线要排在危险区后面，才不会被危险区盖住。
- **删除**：删除选中项，也可以按 Delete。

### 5.7 换底图、改名称和角色

- **换底图…**：给当前阶段换一张图，同样会自动裁成 4:3、缩放到 640×480。如果这张图同时被其他阶段使用，工具会先询问是否一起替换。
- **名称**：板上不显示名称，它方便自己和队友辨认这个阶段。建议写成"角色：一句话描述"。
- **角色**：新建场景时，4 个阶段已经依次设为致因、发生、后果、撤离，一般不用改。
- **灾害**：在"场景"框里修改，4 个阶段一起改。

## 6. 区域对照表：画在哪个区域会显示成什么

区域下拉框会随灾害和角色变化。效果一栏里：
- "**按时刻出现**"表示在 t0–t1 之间逐渐出现；
- "**一直显示**"表示这个区域从第 0 时刻起就显示，时刻参数对它不起作用。

### 致因（所有灾害，地震除外）

| 区域 | 效果 | 推荐画法 |
|---|---|---|
| 0 隐患区轮廓 | 黄色虚线框沿边框流动，慢闪；全图下雨 | 轮廓线，线宽 3 |

### 撤离（所有灾害）

| 区域 | 效果 | 推荐画法 |
|---|---|---|
| 0 撤离路线 | 按时刻从起点延伸到终点，绿色流动虚线，前端白绿闪烁 | 折线，宽 4，t 0→200 |
| 1 危险区 | 一直显示，红色细斜纹缓慢移动 | 画笔、多边形或掩膜 |
| 2 避险点 | 一直显示，绿色圆点慢闪 | 用**避险点工具**，不要画在区域 2 上 |

### 山洪

| 阶段 | 区域 | 效果 | 推荐画法 |
|---|---|---|---|
| 发生 | 0 淹没农田 | 浑水从上游端开始漫开，前沿翻滚 | 种子点放在上游决口处，再选中它用画笔涂出可漫延的范围 |
| 发生 | 1 河道 | 洪峰从上游冲到下游，浪头颜色更深，带浪花 | 掩膜或多边形，渐进方向选"自左向右"或"自上而下"中接近水流的一个；水流是其他方向时，改用种子点从上游放起 |
| 发生 | 2 漫堤 | 河水翻过堤顶，变成溅落的水花 | 沿堤顶画细长多边形 |
| 后果 | 0 淹没范围 | 一直显示，**时刻表示水深**：时刻越小水越深 | 种子点沿河道中线点一排，选中后用画笔涂出淹没范围 |

### 滑坡

| 阶段 | 区域 | 效果 | 推荐画法 |
|---|---|---|---|
| 发生 | 0 裂缝 | 深色裂缝按时刻延伸 | 折线，宽 2–3 |
| 发生 | 1 新鲜土体 | 露出浅色新土 | 多边形，后壁 t0 早，坡脚隆起 t0 晚 |
| 发生 | 2 滑坡体 | 自上而下逐片下沉变暗 | 多边形，渐进方向"自上而下" |
| 发生 | 3 落石 | 第 80 时刻以后，石块沿路径滚落 | 折线从坡上画到坡下，各条路线的 t0 错开 |
| 后果 | 0 堆积体 | 土石堆积，带浅色前沿，逐渐扩展 | 种子点放在坡脚，选中后用画笔涂出堆积范围 |
| 后果 | 1 滑坡后壁 | 一直显示，新鲜土色 | 多边形 |

### 泥石流

| 阶段 | 区域 | 效果 | 推荐画法 |
|---|---|---|---|
| 发生 | 0 泥浆主体 | 泥浆沿沟床涌下，一阵阵浪头，龙头颜色更深 | 掩膜，渐进方向"自上而下"，t 0→150 |
| 发生 | 1 沟壁溅泥 | 龙头经过后，沟壁出现泥点 | 掩膜，t0 晚于主体（如 30→200） |
| 后果 | 0 堆积扇 | 湿泥从沟口扇形展开 | 种子点放在沟口，选中后用画笔涂出扇形范围 |
| 后果 | 1 沟床填满 | 一直显示 | 掩膜或多边形 |

### 地震

| 阶段 | 区域 | 效果 | 推荐画法 |
|---|---|---|---|
| 致因 | 0 断层带 | 一直显示，先微微发光，第 96 时刻主震后红色脉动 | 折线或多边形 |
| 发生 | 0 裂缝 | 第 40 时刻开始震动，之后裂缝出现 | 折线，t0 ≥ 40 |
| 发生 | 2 倒塌房屋 | 从屋顶向下塌成碎瓦堆 | 多边形，渐进方向"自上而下"，t0 ≥ 40 |
| 发生 | 3 落石 | 震后石块滚落 | 折线从坡上画到坡下 |
| 后果 | 0 废墟 | 浅灰碎石覆盖坡脚 | 种子点或多边形 |
| 后果 | 1 地裂缝 | 沿断层的新裂缝 | 折线 |
| 后果 | 2 碎石 | 一直显示，房屋变成瓦砾 | 多边形 |

> **工具里画不了的几项**：地震致因的"震点白环/白环暗边"和"地震波场"、滑坡和地震的"扬尘"，用的是专用的来源类型（quakes、distance、dust）。这几项**不要用工具在对应区域上画**，画了在板上也不显示。确实需要时，在 scene.yaml 里手写（参考 `tools/scenes/quake_village/scene.yaml`）。工具打开已有场景时会原样保留这些项，也能正常预览。

## 7. 撤离图的规则（最重要）

撤离图是整张卡的"答案"，要经得起提问。规则如下：

1. **路线和避险点必须在危险区以外**。工具会自动检查：
   - 避险点有任何一点落在危险区里，就报错；
   - 路线可以从危险区里出发（村子本身就在危险区里），但**离开危险区后不能再进入**。
2. **危险区按灾害类型和这张图的实际地形划定**，不要套用固定形状：
   - **山洪**：河道和可能漫淹的低地。路线不过桥、不沿河走。
   - **滑坡**：滑坡体，以及它下方的滑移、堆积范围（坡脚）。路线横向离开坡体，不沿坡脚走，不往坡下跑到堆积区。
   - **泥石流**：沟道和沟口堆积扇。向沟道两侧的高处撤离，不顺着沟走，不横穿沟口。
   - **地震**：陡坡崩塌落石区、建筑密集区和临河陡岸。避险点选开阔平地，远离建筑和山坡。
3. **工具只能检查重叠**。路线是否沿着真实道路、方向是否背离灾害源、是否需要穿越其他危险地形，需要人逐张图判断。**把判断理由写进"说明 / 取舍理由"栏**，答辩时就靠这些理由回答提问。

推荐顺序：先画危险区，再画路线，最后放避险点。在列表里确认路线排在危险区之后。

## 8. 预览与检查

### 8.1 三种预览

| 模式 | 显示 | 用来检查 |
|---|---|---|
| 标注 | 底图上叠加半透明形状：<br>撤离路线绿色，危险区红色；<br>其他阶段区域 0 黄、1 红、2 蓝、3 紫。<br>折线起点画白圈，终点画实心圆 | 形状位置画得对不对 |
| T 图 | 每个像素属于哪个区域、在哪个时刻出现：颜色表示区域，越深出现越早。白色（显示底图）表示没有标注 | 时间顺序对不对；可以用鼠标悬停在状态栏读数 |
| 动画 | 与板上相同的渲染结果 | 最终效果。点"播放"循环播放；拖动滑条可以停在任意时刻 |

拖动顶点时，画布会临时切回"标注"模式显示，松开鼠标后恢复。

> 动画预览与板子用同一份参考模型（`hazard_v3.render`），**看到的就是板上的效果**。板上 HDMI 的颜色可能和电脑屏幕略有差别。

### 8.2 检查本阶段

点"检查本阶段"，日志会列出：

- 每个区域各有多少像素。某个区域应该有内容却是 0，说明区域选错了。
- 撤离阶段：
  - 是否缺少危险区、路线或避险点（⚠）；
  - 撤离检查是否通过（✓），或者具体在哪里违规（✗）。
  - ✗ 会给出违规的像素数和坐标范围，例如 `route 1 re-enters the danger zone after leaving it at 99 px, x 471..495, y 298..302`，意思是"第 1 条路线离开危险区后又进入了，位置在 x 471–495、y 298–302"。按坐标找到那一段，挪开路线或修改危险区即可。

## 9. 保存与生成

### 9.1 保存

- Ctrl+S，或"文件 → 保存"。"另存为"请存在同一个场景目录里，因为图片和掩膜都是按相对路径引用的。
- 每个阶段的"说明 / 取舍理由"保存在 scene.yaml 的 `note` 字段里，生成 BMP 时会忽略它。
- **注释会丢失**：打开一份手写的、带 `#` 注释的 scene.yaml（例如仓库里现有的 4 张卡），第一次保存时工具会提醒注释会丢失，并先把原文件备份为 `scene.yaml.bak`。建议**现有的卡不要用工具保存**，用工具新建自己的卡。
- 关闭窗口或打开其他场景时，如果有未保存的改动，工具会询问是否保存。

### 9.2 生成场景包

点"**保存并生成场景包**"。工具先保存，再生成全部 4 张图，并附带 gif 动画预览。一般需要几秒到一两分钟，日志出现"✓ 完成"就表示成功。

场景目录下的 `out/` 里有：

| 路径 | 内容 |
|---|---|
| `sd/PIC1.BMP` … `PIC4.BMP` | **拷到 SD 卡根目录**的文件 |
| `overview.png` | 总览图：每行一个阶段，各列依次为 t=0、t=120、t=239、t=239 暗相、T 图 |
| `gif/PIC1.gif` … | 每个阶段的动画预览，可以发给队友看或放进答辩 PPT |
| `expected/`、`tmap/` | 仿真比对用的参考图，一般不用看 |

生成的 BMP 每写一张都会读回来自检。exe 生成的结果和命令行运行 `make_scene_pack.py` 逐字节相同。

## 10. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 点了一下没有出现新点，而是拖动了某个顶点 | 列表里还选中着一个形状，点在了它的顶点附近，见 5.1。先按 Esc 取消选中再画 |
| 种子点画完整张图都被染色 | 没有设种子掩膜或最远距离，见 5.2 |
| 想新画一块区域，结果涂到了上一块上 | 上一块还处于选中状态，画笔会接着往它上面涂。先按 Esc 取消选中，再改区域、开始涂，见 5.3 |
| 橡皮擦没反应，日志提示"只擦选中的形状" | 先在列表里选中要擦的那一项 |
| 场景目录里多了 `brush_….png` | 这是画笔区域的文件，被 scene.yaml 引用，不要删除。拷贝场景时要一起带走 |
| 路线动画从避险点往村子里流 | 折线画反了。删除后从村子一端重新画 |
| 路线被危险区盖住，看不见 | 在列表里把路线下移，排到危险区后面 |
| 某个区域在动画里不显示 | 区域选错了（检查本阶段时该区域像素数为 0）；或者画在了"扬尘""震点"这类工具不支持的区域上，见第 6 节 |
| 日志报"掩膜是 …，需要 640x480" | 掩膜和底图尺寸不一样。在 `picN.png` 上画掩膜就不会出错 |
| 日志报"算不出 T" | 某个形状参数异常，比如 t0 大于 t1，或者掩膜文件被移走了。按提示修改，或者 Ctrl+Z 撤销 |
| 生成失败 | 看日志里的报错。最常见的是撤离检查不通过（见 8.2），以及底图尺寸不对（用"换底图…"重新导入） |
| exe 启动很慢 | 单文件 exe 每次启动都要先解压，等几秒即可 |
| 改了 Python 代码，exe 里没有变化 | exe 要重新打包：`python -I tools/build_annotate_exe.py` |

## 11. 给维护者

- 源码 `tools/annotate_scene.py`。它直接调用 `make_scene_pack.stage_t3` 计算 T、调用 `hazard_v3.render` 预览动画，所以与生成工具和 RTL 参考模型始终一致。
- 打包 exe：`python -m pip install pyinstaller`（只需一次），然后运行 `python -I tools/build_annotate_exe.py`。exe 输出到 `tools/`，不入库。
- 改了 `annotate_scene.py`、`make_scene_pack.py` 或 `hazard_v3.py` 中的任何一个，都要重新打包 exe。
- 工具只支持 format 3、640×480、正好 4 个阶段的场景。scene.yaml 的完整格式见 `tools/scenes/README.md`。
- 画笔区域保存为场景目录里的 `brush_p阶段_序号.png`，在 scene.yaml 中是普通的 `type: mask` 来源，make_scene_pack.py 不需要为画笔做任何改动。拷贝或提交场景时，要连同这些 png 一起。
