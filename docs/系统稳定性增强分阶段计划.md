# 系统稳定性增强分阶段计划

2026-10-05。开发分支 `feature/system-stability-v0.4.0`，基线 `e76be02` / 已验收 v0.3.0。用户选择基础稳定性与 SD 恢复，逐阶段上板再推进。当前仅执行 S0；S1 未开始。

## 共同闸门

每阶段形成一个可验证单元：修改、专项 ModelSim、受影响回归、TD 综合/布局布线/bitgen、固定候选和文档。含新 bit 的阶段等待用户上板确认后才进入下一阶段。只有用户明确验收后才建立板级标签并推送该验收节点；本地候选、失败节点不上传 GitHub。正常独立模块阶段只要求仿真，不强制制造 bit。

标签 `v0.4.0-stability-sN-local.K` 标识本地证据，`v0.4.0-stability-sN-board.K` 标识用户已验收同一候选；不移动旧标签。恢复下载始终使用已验收固定 bit。ModelSim PASS 不代替物理 SD/SDRAM/HDMI，TD 成功不代表时序收敛。

## 工程理解及参考边界

SD SPI 命令/扇区链路 -> bmp_read 扫描裸扇区并产生 BGR/RGB 像素 -> 写 FIFO/SDRAM 非显示缓冲 -> 显示交接握手 -> 图片编号提交及音频 CDC -> HDMI TMDS/PHY。内存写地址翻转抵消 BMP bottom-up；当前仅支持正高 640x480、24 位未压缩图。按键控制和 AUTO 请求具有既定挂起及优先级语义。

读取来源：桌面“第4课_系统稳定性 等2项/第4课_系统稳定性增强.md”及同目录“第4课_系统稳定性”14 个参考模块。参考是设计输入，不整包导入；media_recovery_fsm 默认 MAX_RETRIES=2，与课文建议 1 次不一致，且无本项目取消/就绪握手，必须适配。fast_boot_gate 只门控已完成图片，并不能替本项目建立后台扫描调度。Flash/UART/OSD模块依赖另一套接口和硬件配置。

课程示例必须修正：全宽尺寸比较、加法溢出、DIB 与像素偏移一致性；仅凭 BM 和不可信 file_len 跳过可漏掉后续好图；非 BMP/MP3 仍逐扇区扫描。裸扇区没有真实文件 EOF，长度字段与像素计数不能证明截断文件之后的扇区不是其他数据。SD CRC 也只验证传输，不验证文件归属；不得宣称支持 FAT 碎片文件或检测任意逻辑截断。

写帧当前没有取消接口；半帧失败可留下等 FIFO 的写事务。因此 S2 先独立验证故障检测，取消能力须随 S3 一起完成后才允许集成半帧重试；不能发布仅退出 bmp_read 的恢复实现。

|---|---|---|---|

| S1 头校验与错误 | bmp_read 新增 8 位 sticky 错误、单拍 load_error；sd_card_bmp 接收头拒绝事件；每次扇区头重新清字段；头不合格不发写请求 | 正常图与签名/DIB/全宽尺寸/planes/bpp/压缩/偏移/长度错误专项；原控制回归；TD；坏头拒绝和正常播放上板 | 未开始 |
| S2 扫描/检测 | 有界且不溢出的可信长度快跳，否则 +1；每扇区无进展计时与等待写应答计时；输出像素严格限量并计数；失败脉冲与正常完成分离 | 模拟头、数据、应答停顿/提前结束/末字节同拍/超长尾数据；下一事务清零；独立单元不接半帧重试；扫描集成候选上板 | 未开始 |
| S3 取消/恢复 | SD 域请求 -> 内存域写事务取消 -> 等当前突发安全结束/清写 FIFO/确认空闲 -> 返回 SD；丢弃旧完成；非显示缓冲重用；有限重试/跳过 | 三组异步时钟与故障位置；取消确认前不能新写；半帧不提交；旧完成不影响新事务；真实图/坏图混排上板 | 未开始 |
| S4 SD 协议恢复 | 命令 6 字节与 R1 分阶段；完整初始化才 ready；初始化/token 总等待限次；扇区失败/CRC16 贯通上层；受控重新初始化 | 保留卡侧状态模型，覆盖无响应/无 token/CRC/热复位/重插；全回归/TD；用户原卡0/卡2场景上板 | 未开始 |
| S5 参数/诊断及结项 | 整理集中参数，数码管失败提示与状态文档；冻结正式候选；全回归/TD及历史归档 | 正常图、混合坏图、全坏图、无卡、重插KEY3、密集翻图复位及30分钟AUTO上板 | 未开始 |

## 接口与行为约定

- BMP 8 位错误：00 无错，31 签名，32 尺寸，33 planes，34 位深，35 压缩，36 偏移，37 数据数量/长度不足，38 上游，39 DIB，3A 超时。错误保持到新事务或复位，失败/成功事件各单拍；scan_done 不等于扫描成功。SD 初始化、响应、token、CRC 错误使用独立类别，向上层汇总。
- 保持 640x480、原扫描 0..131071、最多4图、MAN 默认、3秒AUTO、音量128。尺寸全32位比较；当前拒绝负高，不改变写地址翻转。解析只输出像素区 307200 个像素，尾数据不成为额外像素。
- 默认读无进展500ms、写应答500ms、重试1次；计时使用足够位宽的周期运算和可缩短的测试参数。500ms是单次等待而非整张图/全扫描上限。SD初始化默认总限时5秒、重建最多2次；板级正常卡若超时应分析并修改参数后产生新候选。
- S1头拒绝即可释放任务；S3以后任何写事务失败必须等取消确认才释放/重试。头/格式错误也最多重试1次；MAN失败保持当前图并接收后续请求；AUTO尝试下一个未失败索引。首图失败依次尝试剩余索引；本轮所有候选失败后降级停止循环。坏图位图在重新扫描/KEY3时清零。
- 错误恢复不产生显示提交或提示音。显示编号和提示仍只在真实交接确认后更新。无首图时保持启动画面并静音；已有首图的局部SD恢复保留帧，KEY3全局复位仍回启动画面/静音。
- 不增设卡检测引脚；不能把FF数据当拔卡。重新插卡后KEY3重初始化是明确用户恢复方式，不承诺无电源控制条件下所有卡自动热插拔恢复。
- 诊断优先使用现有数码管：正常恢复1..4，降级显示E；详细类别写入测试/文档。UART/OSD、新引脚、Flash持久化、独立解码重构、快启、FAT文件系统另立计划，本轮不接入。
